Level-Based Resource Manager Test

This demonstrates the new level-based resource management system with pluggable loaders.

System Overview

Key Concepts:
• Levels: Collections of resources mapped to file paths
• Loaders: Pluggable handlers for different file types
• Integer IDs: Resources are assigned numeric IDs internally
• Automatic Loading/Unloading: Only level resources are kept in memory
ResourceLoader Interface: - GetFileExtensions() // Returns array of supported extensions - Load(file, resourceId) // Load file into engine with numeric ID - Unload(resourceId) // Unload resource by numeric ID
