RetroWatch SDK

Everything you need to build and upload apps for RetroWatch.

Prerequisites

Install these before setting up the SDK:

  1. VS Code — required for the extension and build tasks.
    Download VS Code
  2. Arm GNU Toolchain — the ARM cross-compiler (arm-none-eabi-gcc). Install to C:\devkitPro\RetroWatch.
    Download ARM Toolchain
  3. Python 3 — needed for flashing and upload tools. Check "Add to PATH" during install.
    Download Python
  4. SEGGER J-Link (optional) — only needed for on-device debugging via SWD.
    Download J-Link

VS Code Extension

Install the RetroWatch extension to get build tasks, upload commands, and one-click SDK setup inside VS Code.

Download Extension (.vsix)

SDK Bundle

Self-contained SDK with ARM toolchain, embedded Python, make, libraries, and project templates. ~100 MB.

Download SDK Bundle (.zip)

Quick Start

  1. Install the .vsix in VS Code: Ctrl+Shift+P → Install from VSIX
  2. Run Ctrl+Shift+P → RetroWatch: Setup Environment — this downloads and installs the SDK automatically.
  3. Open a template project and build with Ctrl+Shift+B.

Or use the standalone installer: extract the SDK zip and run setup.bat.
